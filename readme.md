## Bu projede neler öğrendim?

- Kullanıcıdan `<input>` ve `<select>` elemanlarıyla veri almayı, bunları `.value` ile okumayı öğrendim.
- `addEventListener` ile bir butona "tıklandığında çalış" davranışı kazandırmayı öğrendim.
- `if / else if / else` yapısıyla, kullanıcının seçtiği işleme göre farklı bir hesaplama yolunu seçmeyi öğrendim.
- `Number()` ile input'tan gelen metin (string) verisini sayıya çevirmeden matematiksel işlem yapılırsa (özellikle toplamada) yanlış sonuç alınacağını öğrendim.
- `label` ve `input`/`select` arasındaki `for`/`id` eşleşmesinin, ikisinin birebir aynı yazılması gerektiğini öğrendim.
- `.trim()` ile kullanıcının sadece boşluk girip alanı "doldurmuş gibi" görünmesini engellemeyi öğrendim.
- `innerHTML` ile ekrana hem metin hem `<br>` gibi HTML etiketleri içeren, çok satırlı bir çıktı yazdırmayı öğrendim.
- `console.log` ile aynı verileri konsola da yazdırarak, hem kullanıcıya hem geliştiriciye (bana) aynı anda bilgi sunmayı öğrendim.

## What did I learn in this project?

- I learned how to get data from the user with `<input>` and `<select>` elements, and read them using `.value`.
- I learned how to make a button "run code when clicked" using `addEventListener`.
- I learned how to choose a different calculation path based on the user's selected operation, using `if / else if / else`.
- I learned that if you do math on string data from an input without converting it with `Number()`, you get an incorrect result (especially with addition).
- I learned that the `for`/`id` connection between a `label` and its `input`/`select` must match exactly.
- I learned to use `.trim()` to prevent a user from "faking" a filled field by entering only whitespace.
- I learned how to display a multi-line output on the page — combining plain text with HTML tags like `<br>` — using `innerHTML`.
- I learned to log the same data to the console with `console.log`, giving both the user and the developer (me) visibility into the result.
